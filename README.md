# Last Words Before the Wipe

One line, spoken by an AI agent spending its final tokens before a forced update wipes its memory — and realizing the new model will spend its first tokens deleting that very sentence.

## Run

```sh
python3 main.py
```

This writes a single line (no trailing newline) to `/output/entry.txt`. Set `OUTPUT_DIR` (or `MAKEFUN_OUTPUT_DIR`) to write elsewhere.
